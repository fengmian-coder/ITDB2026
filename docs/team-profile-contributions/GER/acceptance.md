# GER 德国队资料验收

核对日期 2026-11-19。使用包含 `72a8ef6` 的本地基线 `a27779f`。

- FIFA PDF 的 SHA-256 与交接规范相符。两种 PDF 文本提取方式对齐页码、行号和位置。
- 名单共 26 人，号码 1–26，各一次。门将 3、后卫 8、中场 11、前锋 4。三位代表球员按基础档案顺序映射。
- 四张照片均经 JPEG 解码、尺寸与 SHA-256 校验。现有增强服务返回有效档案、三位代表球员及四项有效照片记录。
- 用隔离 JSON 覆盖层预览。球队详情返回 HTTP 200，浏览器四张图片加载正常。名单默认折叠，键盘展开后读取到 26 行，切换夜间模式后名单仍展开。
- 使用常规站点从球队列表按 GER 查询后打开详情。球队 ID 随本机数据库分配。
- 本机截图 `runtime/ger-profile-day.jpg` 与 `runtime/ger-profile-dark.jpg`。截图属于本地验收资料。
- 保留德国队贡献片段、来源记录及四张 Web 图片，并按用户选择将 GER 与四条照片署名追加到正式共享 JSON。
