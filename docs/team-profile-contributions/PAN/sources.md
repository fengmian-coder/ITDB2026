# PAN 巴拿马队资料来源

## 名单与译名

- [FIFA 固定名单第 33 页](https://fdp.fifa.org/assetspublic/ce281/pdf/SquadLists-English.pdf#page=33)记录号码、位置、姓名、俱乐部、国家队出场和进球。版本为 `2026-07-19 22:34 UTC · Version 1`，SHA-256 为 `02a0a9beb5d219e7cc0aedde19273e9a3bfe4818ecd600d37804b8801dd96d94`。
- 26 人按门将 3、后卫 11、中场 8、前锋 4 核对。代表球员沿用基础档案的 #15 Eric Davis、#20 Anibal Godoy、#17 Jose Fajardo。
- [PP 体育巴拿马名单](https://www.ppsports.com/article/news/2543071.html)用于参考常用译名。乔瓦尼·拉莫斯、阿萨里亚斯·隆多尼奥等较少见姓名采用人工音译，待复核。阵容、位置和俱乐部以固定 FIFA PDF 为准。

## 球队与教练概况

- [FIFA 巴拿马世界杯历史](https://www.fifa.com/en/tournaments/mens/worldcup/canadamexicousa2026/articles/panama-team-profile-history)核实巴拿马于 2018 年首次参赛、未参加 2022 年世界杯，2026 年为第二次参赛。该报道也确认巴拿马以中北美洲及加勒比海足联预选赛第三阶段 A 组第一直接晋级。
- [FIFA 克里斯蒂安森任命报道](https://inside.fifa.com/en/tournaments/mens/worldcup/qatar2022/news/thomas-christiansen-named-panama-head-coach)记录 2020 年上任。
