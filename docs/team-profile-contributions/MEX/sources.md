# MEX 墨西哥队资料来源

## 名单与译名

- [FIFA 固定名单第 28 页](https://fdp.fifa.org/assetspublic/ce281/pdf/SquadLists-English.pdf#page=28)提供号码、位置、姓名、俱乐部、国家队出场和进球。版本为 `2026-07-19 22:34 UTC · Version 1`，SHA-256 为 `02a0a9beb5d219e7cc0aedde19273e9a3bfe4818ecd600d37804b8801dd96d94`。
- 26 人按门将 3、后卫 7、中场 8、前锋 8 核对。代表球员沿用基础档案的 #23 Jesus Gallardo、#17 Orbelin Pineda、#9 Raul Jimenez。
- [墨西哥 26 人名单中文报道](https://www.br-cn.com/static/content/news/nm_news/2026-06-03/1511677040598850748.html)用于参考常用译名。布赖恩·古铁雷斯、奥贝德·巴尔加斯等较少见的姓名采用人工音译，待复核。名单、位置和俱乐部统一与固定 FIFA PDF 对齐。

## 球队与教练概况

- [FIFA 墨西哥世界杯档案](https://www.fifa.com/en/tournaments/mens/worldcup/canadamexicousa2026/articles/mexico-team-profile-history)和[FIFA 墨西哥东道主历史](https://www.fifa.com/en/tournaments/mens/worldcup/canadamexicousa2026/articles/mexico-fifa-world-cup-hosts)用于核对历史成绩、2022 年小组赛和 2026 年联合主办。
- [FIFA 阿吉雷任命报道](https://www.fifa.com/es/tournaments/mens/worldcup/canadamexicousa2026/articles/javier-aguirre-nuevo-entrenador-de-la-seleccion-mexicana)记录他第三次出任墨西哥主教练，以及 2002 年、2010 年带队参加世界杯的经历。
