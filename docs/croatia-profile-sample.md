# 克罗地亚球队图文样板（2026-11-18）

最初为 CRO 启用：精简简介、位置人数、主教练资料照、三位代表球员图文卡，以及默认折叠的 26 人完整名单。后续已扩展到默认列表前三队：乌兹别克斯坦、乌拉圭、伊拉克，详见 [首三队扩展记录](team-profile-rollout-2026-11-19.md)。目前共 4 队使用此版式，其余 44 队沿用原有版式，球队旅程、PK 和赛事统计继续复用原服务。扩展未改动现有开发库的记录或表结构，也未重新导入数据。

## 数据与维护

- 基础档案仍由 `TeamProfileService`、`TeamProfileForm` 及既有后台维护，三位代表球员的输入约定不变。
- 新增 `data/team-profile-features-2026.json` 保存 CRO 的增强展示、完整名单和照片对应键；`TeamProfileFeatureService` 只读加载。完整名单及照片目录暂通过这份版本文件维护。
- 完整名单来自 [FIFA 官方名单第 13 页](https://fdp.fifa.org/assetspublic/ce281/pdf/SquadLists-English.pdf#page=13)，沿用原档案的 2026-07-19 22:34 UTC / Version 1。原 PDF SHA-256 为 `02a0a9beb5d219e7cc0aedde19273e9a3bfe4818ecd600d37804b8801dd96d94`。
- 按原 PDF 表格核对 26 个不同球衣号码：门将 3、后卫 8、中场 9、前锋 6。姓名、位置、俱乐部与累计数字来自同一页；不更新为实时转会信息。
- 仅在基础档案的来源链接、版本均匹配时展示样板。简介经过后台自定义后优先保留自定义内容；教练或代表球员的姓名改变时，不继续套用原人物照片。
- 原 `data/team-profiles-2026.json` 和数据库已有 `profile_json` 保持原样；已有机器拉取本轮文件后即可显示，无需执行增量命令。

## 图片

四张图片使用 Wikimedia Commons 的 500px 预览版并本地保存，避免页面依赖外网。图片原样存储，展示时仅由 CSS 裁切。记录作者、拍摄日期、来源页、实际下载地址、许可和 SHA-256 的清单位于 `web/images/team-profiles/credits.json`；完整署名亦可在公开页面“名单与图片来源”中展开查看。

后续调整：三位球员已换为 Bryan Berlin / WikiPortraits 同场拍摄的 2026 世界杯比赛照（CC BY-SA 4.0），现场图不冒称 FIFA 官方定妆照；教练保留标注 2018 年的资料照。旧三张球员照已从展示目录移除，本机历史副本保留在忽略的 runtime/backups。图片各按来源许可使用，不将其许可套用于整个项目源码。详情见图片目录 README。

## 中文与概况信息

“2026 · 球队档案／认识这支球队”改为单一“球队概况”，展示 2018 亚军、2022 季军及本届队长；教练增加 2017 开始执教和两届世界杯奖牌经历。球队、队长与教练信息取自 [UEFA 本届球队介绍](https://www.uefa.com/european-qualifiers/news/02a6-20d159312e19-b662016c6c47-1000--croatia-at-the-world-cup-2026-squad-fixtures-group-and-hi/)，不采用该页与含本届口径不一致的参赛次数数字。

26 位球员及俱乐部的中文显示名参照 [央视正式名单报道](https://sports.cctv.cn/2026/06/02/ARTIO1WSRREOnwtRCY4ALBdR260602.shtml)；比赛编号、位置、俱乐部归属及累计数据仍以原 FIFA 名单快照为准。球员卡片和完整名单中的姓名、俱乐部统一默认显示“中文（原文）”，原文使用较小、较浅的文字，长名称自然换行，无需切换开关。未以译名覆盖原始姓名或既有数据库。

管理员自定义的球队简介、教练介绍继续优先保留。后台改教练身份时，旧照片与中文别名同时撤下，避免给另一人物套用原教练资料。

## 验证

`php tests/integration/team-profile-feature.php` 是本机只读检查：核对完整名单与位置人数、照片身份及资源哈希、版本与人物变更回退、自定义介绍保留、48 个球队页面和原赛事统计，并检查默认折叠状态与署名链接。

不运行旧的在开发库中写入临时人物／比赛的测试。本轮新增数据文件、图片和 UI 改动尚需用户自行提交、推送，并与 C 同步这份只读增强结构。
