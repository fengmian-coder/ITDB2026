# A 模块本机使用说明

## 2026-11-12 联调更新

本机已同步队友最新主线代码，并通过现有导入工具载入 48 队、104 场比赛、16 座场馆及 8 篇已发布故事。团队和附件记录保持原样；其他电脑需按仓库说明自行导入赛事数据，Git 同步不会自动写入数据库。

前台导航按“球队、比赛、数据总览”组织。在“球队”用中文名、英文名或 FIFA 代码搜索；点击整张卡片进入球队详情查看 DNA，通过球队旅程查看比赛，再进入比赛详情或制作纪念卡。列表采用左侧国旗、右侧中文名和英文名，FIFA 代码在详情页展示。分页采用绿色当前页和“上一页／下一页”按钮。球队详情、球队对比和旅程均高亮顶部“球队”。纪念卡也可从导航进入，选择球队后确认，再选择比赛并确认，填写感想后下载 PNG。

“球队”列表右上角的“球队对比”可直接选择两支球队；详情页点击“与其他球队比较”会预选当前球队。对比页集中展示双环胜平负图、胜率及完整统计表，可交换双方。

“数据总览”展示晋级流向、进球排名、攻防分布和阶段统计四类赛事图表。选择追踪球队后，攻防数据卡提供球队详情、预选该队的对比页及球队旅程入口。刷新会保留仍有效的所选球队。图表需要启用 JavaScript。尚未提供赛事数据时，图表页显示暂不可用提示。

本轮验证范围及待补素材见 `docs/handoffs/a-integration-2026-11-12.md`。

## 打开网站

本机地址：`http://127.0.0.1:8080/`。服务已经启动；如果以后重启电脑或关闭了服务，在项目目录双击 `runtime/start-dev.cmd`，保持命令窗口运行。该脚本只适用于当前电脑，停止服务按 Ctrl+C。

管理员登录：`http://127.0.0.1:8080/index.php?r=auth/login`。本次创建的本地账号为 `a_admin`，密码请在自己电脑上打开 `runtime/admin-login.txt` 查看，不要提交这个文件。网站管理员密码和 MySQL root 密码是不同的密码。

## 修改团队资料

后台已统一为左侧模块导航和顶部账号工具栏。“管理概览”展示真实内容数量；“网站内容”分组包含团队、作业管理与留言，“赛事资料”分组包含届次、比赛、场馆与故事。页面中的新增、筛选、保存、删除及回复仍使用原有业务规则。浏览器如保留旧样式，请按 Ctrl+F5 刷新。

登录后台后进入“团队与成员”，点击“管理资料”。“编辑团队”可以改团队名称与简介；成员行的“编辑”可以填写真实姓名、负责方向、具体分工与显示顺序。顺序数字越小越靠前。保存后，打开前台“关于我们”即可查看。

当前已根据个人作业 3 的截图填入四位成员：A 卢苑、B 胡乐妍、C 袁颢心、D 张馨月，负责方向与介绍也已同步。初始化命令使用同一份 `data/project-members.json`；日常维护继续通过后台进行。

团队图片路径可留空；如需图片，先将图片放进 `web/images`，再填写类似 `images/team/logo.png` 的相对路径。

新增成员使用“新增成员”。删除前勾选该行确认框；成员有关联个人作业时不能删除。团队有成员或作业文件时也不能删除。

## 管理课程作业

后台进入“作业管理”，点击“上传作业”。选择团队作业时，所属成员留空；选择个人作业时，选择同一团队中的成员。填写标题并选文件后保存。

编辑时不选新文件，会保留现有文件；选新文件则替换。更改团队/个人类别后，文件自动进入对应目录。单个文件不超过 20 MB。

前台“作业下载”中已登记 A 的三份个人报告、作业 1 源码包、作业 2 Axure RP，以及一份团队协作规范。其他成员的作业和最终团队文档仍需要小组上传。

## 制作纪念卡

正式球队与比赛数据导入后，打开“纪念卡片”，选择球队并点击“确认选择”，再选择该队的比赛并再次确认。写下感想，可选添加照片，点击“下载 PNG 纪念卡”。整个流程无需登录，个人感想与照片不会提交到服务器；未填写感想时不会自动填入口号式文本。

比赛时间标注为北京时间；加时比分为累计场上比分，点球单独显示；未开赛的比赛不显示虚构比分。

目前数据库尚无正式赛事数据，因此首页显示 0 支球队、0 场比赛，纪念卡页提示资料整理中。首页的“卡片示例”复用个人作业 2 的比赛和照片，供查看完成效果，不会写入正式比赛数据。团队资料和作业下载可以正常使用。B/C 的正式数据导入后，页面会自动读取，不需要手工修改首页数字。
