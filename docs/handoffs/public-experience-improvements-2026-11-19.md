# 前四项体验改进：实现与验收

日期：2026-11-19。用户已明确选择先修改纪念卡内容丢失、精选详情过长、留言关联不直观、文字偏技术化这四项，整体视觉精修留待后续讨论。

## 本轮结果

1. 纪念卡选择改为同页更新比赛选项和预览。感想、照片及文件输入保留在当前编辑页，切换球队时先清空旧比赛，快速切换取消旧请求；更新失败恢复上次成功选择。增加字数状态与移除照片按钮，启用 JavaScript 时隐藏重复的确认按钮。原 GET 路由、队伍／比赛身份校验、1200×800 PNG 导出及不上传感想／照片的处理方式保留。
2. 精选故事与时间轴改为前后通栏。默认显示进球、乌龙、红牌、点球进球／未进等明确类型的关键事件，可展开全部；全部原事件节点、内容、顺序及 anchor 均保留，指向折叠事件的链接会自动展开。无 JavaScript 时直接展示完整时间轴。制卡与留言入口在正文前后均可使用。
3. 留言关联改为北京时间日期筛选和具体对阵选择，不再要求输入内部 ID。从比赛详情进入时，仍按原 `match_id` 自动选中，并显示双方名称与开赛时间。提交字段仍为 `related_match_id`，沿用 CSRF、必填／存在性校验、待审核及公开规则。可不关联比赛；筛选日期无比赛时有说明。无 JavaScript 时可直接从完整名单选择。
4. 已知事件与时段显示中文，例如进球、黄牌、上半场、加时下半场；未知代码原样保留，不凭描述猜测事件分类。小组赛明确显示“不设加时／不设点球大战”；有足够比分依据的完赛淘汰赛显示“未进行／未进入”，不明情况保留未注明提示，不将 null 一律判断为未发生。

纪念卡保留的是当前页面内的编辑状态，没有将照片写入浏览器持久存储；刷新或关闭页面不会自动恢复草稿。

## 随后截图反馈：国旗与留言页精简

用户指出比赛头部国旗和留言页文字层次问题。实查沙特与乌拉圭均正确加载对应的本地 SVG，问题为详情头部沿用了列表小尺寸。`_team.php` 增加可选 `flagSize`，只在比赛详情头部传 `lg`，桌面 96×72、手机 64×48，保持完整比例，列表／旅程仍用原默认值，没有换国旗文件。

留言页补充仅本页加载的 `web/css/guestbook.css`：表单最大宽度 960px；标签、输入、选择和按钮文字统一 16px；普通文字使用同一正文色，辅助说明统一 14px。日期与对阵在桌面并排，手机分行。选择标签缩短为“双方 · 月-日 时间”，不重复展示场次号及第二行“已关联”文本；完整关联通知保留给读屏器，无比赛日期的提示仍可见。“北京时间”只说明一次，审核说明移到提交按钮旁。没有改变服务器提交字段或审核流程。

本次复核：157 项国旗资源／安全回退检查及 36 项浏览器专项通过，PHP／JS 语法检查通过；实际查看 1440px 日间、390px 夜间及日期清除按钮展开状态。证据在 `runtime/flag-guestbook-refinement-20261119/`。原一轮其他未提交更改与交接记录保留，仍未暂存、提交或推送。
